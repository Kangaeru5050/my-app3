# 3D Minecraft Web (Three.js MVP)

HTML5 / CSS / JavaScript と [Three.js](https://threejs.org/) を使用して構築されたブラウザ上で動作する 3D ボクセルワールド（マインクラフト風ゲーム）の MVP です。
GitHub Actions により GitHub Pages に自動デプロイされます。

🎮 **公開URL (GitHub Pages):**  
[https://kangaeru5050.github.io/my-app3/](https://kangaeru5050.github.io/my-app3/)

---

## 🕹️ 操作方法

| キー / 操作 | 動作 |
|---|---|
| **W, A, S, D** | 前後左右に移動 |
| **Space** | ジャンプ |
| **マウス移動** | 視点移動 (Pointer Lock による360度カメラ) |
| **左クリック** | ブロックを破壊（破壊音 & パーティクル演出） |
| **右クリック** | ブロックを設置（足元・頭上との干渉防止機能つき） |
| **1 〜 6 キー** / **マウスホイール** | 所持ブロックの切り替え（草・土・石・原木・木材・レンガ） |
| **ESC** | 一時停止 / マウスポインタ解放 |

## ✨ 主な特徴・実装内容

1. **シングルファイル (index.html) 実装**:
   - 外部画像ファイルやサウンドファイルへの依存なし。
   - ネットワークの遅延や CORS エラーによるテクスチャ欠けのリスクがゼロ。
2. **手続き型ピクセルテクスチャ (Procedural Pixel Art)**:
   - HTML5 Canvas 2D API を使用して、16×16 ピクセルのレトロ調マインクラフトテクスチャをブラウザ上で動的生成。
3. **Web Audio API によるリアルタイム効果音合成**:
   - ブロック破壊音・設置音・ジャンプ音をオシレーターとノイズバッファでリアルタイム合成。
4. **本格的なボクセル物理 & 衝突判定 (AABB)**:
   - 軸分離（X・Z・Y）による精密な当たり判定。めり込み防止や自然な段差乗り上げ・着地を実現。
5. **レイキャスティング**:
   - 画面中央の照準からレイを飛ばし、見ているブロックを枠線ハイライト。面法線ベクトル（normal）に応じたブロック配置。
6. **GitHub Actions 連携**:
   - `.github/workflows/deploy.yml` により、`main` ブランチへのプッシュで自動的に GitHub Pages にビルド＆公開。
